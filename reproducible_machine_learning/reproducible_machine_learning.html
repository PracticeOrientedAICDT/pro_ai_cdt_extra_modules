MLOps

  • Definition: MLOps, short for Machine Learning Operations, is a set of practices and tools that aim to streamline and automate the deployment, monitoring, and management of machine learning (ML) models in production.

  • MLOps is a structured approach to manage the end-to-end developing, deploying and mantaining Machine learning models.

  • Improves the model management, deployment speed and quality control.

This is where MLOps comes into play. MLOps, or Machine Learning Operations, encompasses a set of practices and tools that streamline and automate the deployment, monitoring, and management of machine learning models in production.

MLOps provides a structured approach to manage the end-to-end development, deployment, and maintenance of machine learning models.

MLOps can be classified also as a “culture” in the organization.

MLOps

  • The MLOps lifecycle emphasizes collaboration between data scientists, machine learning engineers, DevOps teams, and domain experts.

  • By following this structured approach, companies can delivery the full potential of machine learning while minimizing risks and operational challenges.

  • Frequently requires a set of open source software for the implementation.

It emphasizes collaboration between data scientists, machine learning engineers, DevOps teams, and domain experts. By following this structured approach, companies can unlock the full potential of machine learning while minimizing risks and operational challenges.

Concept and Data Drift

  • Main factors:

    • Concept Drift

    • Data Drift

Model degradation can result from concept drift, where the relationship between inputs and outputs changes over time, and data drift, which occurs when input data changes. Monitoring is crucial to address these issues.

Concept Drift

  • The relationship between the model inputs and outputs changes overtime

  • The model is not aware of this change

  • Usually this change happens due to external factors

Data Drift

  • The change occurs when the model data input changes

  • Usually happens due to an increased relevance of “under-learned” segments.

Concept and Data Drift

Data Drift

  • The change occurs when the model data input changes

  • Usually happens due to an increased relevance of “under-learned” segments.

Data Drift

  • Statistical statistical measures to compare past and current features:

    • Mean/median

    • Standard deviation

    • Minimum and maximum values

    • Correlations

Data Drift

  • For continuous values, one can use distances and/or hypothesis tests such as:

    • Kullback–Leibler Distance

    • Kolmogorov-Smirnov Test

    • Population Stability Index (PSI)

    • Hellinger Distance.

Data Drift

  • For categorical variables, you can use the chi-square test, entropy, cardinality or frequency of the feature.

  • If there are many features, we can use some dimensionality reduction technique.
