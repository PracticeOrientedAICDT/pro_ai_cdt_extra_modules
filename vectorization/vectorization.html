Author

Daladier Sampaio Neto

What is Vectorization?

  • Vectorization refers to applying operations on entire arrays instead of using explicit loops.
  • It utilizes optimized C and Fortran implementations under the hood.
  • Commonly used in NumPy, Pandas, and TensorFlow.
  • Replaces slow for loops with efficient operations on entire arrays.

Why Use Vectorization?

  • Speed: Optimized implementations outperform loops.
  • Readability: More concise and clear.
  • Memory Efficiency: Operates directly on arrays without extra overhead.
  • Better CPU Utilization: Takes advantage of SIMD (Single Instruction, Multiple Data) operations.

Vectorization with NumPy: Element-wise Operations

import numpy as np

arr = np.array([1, 2, 3, 4, 5])

# Loop-based approach
squared_loop = [x**2 for x in arr]

# Vectorized approach
squared_vectorized = arr ** 2

print(squared_vectorized)
[ 1  4  9 16 25]

Vectorization with NumPy: Mathematical Functions

arr = np.array([0, np.pi / 2, np.pi])

# Loop-based approach
sin_loop = [np.sin(x) for x in arr]

# Vectorized approach
sin_vectorized = np.sin(arr)

print(sin_vectorized)
[0.0000000e+00 1.0000000e+00 1.2246468e-16]

Vectorization with Pandas

import pandas as pd

df = pd.DataFrame({'A': [1, 2, 3, 4]})

# Using apply (slow)
df['B'] = df['A'].apply(lambda x: x**2)

# Vectorized (fast)
df['B'] = df['A'] ** 2

print(df)
   A   B
0  1   1
1  2   4
2  3   9
3  4  16

Performance Comparison: NumPy vs Loop

import time
import numpy as np

arr = np.random.rand(10**6)

# Loop-based
start = time.time()
result_loop = [x**2 for x in arr]
print("Loop time:", time.time() - start)

# Vectorized
start = time.time()
result_vectorized = arr ** 2
print("Vectorized time:", time.time() - start)
Loop time: 0.12875771522521973
Vectorized time: 0.0

Vectorization in NumPy: Dot Product

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

# Loop-based approach
result_loop = [[sum(a * b for a, b in zip(A_row, B_col)) for B_col in zip(*B)] for A_row in A]

# Vectorized approach
result_vectorized = np.dot(A, B)

print(result_vectorized)
[[19 22]
 [43 50]]

Vectorization vs Loops: Visual Intuition

  • Looping processes one element at a time.
  • Vectorization applies one operation to all elements at once.
  • Think of:
    • Loop → preparing 100 sandwiches one by one
    • Vectorization → using a sandwich-making machine that does all 100 at once

Vectorization: Memory Layout and Contiguity

  • NumPy arrays are stored in contiguous memory blocks (C or Fortran order).
  • Vectorized operations exploit:
    • CPU vector registers (SSE, AVX)
    • Efficient pointer arithmetic
    • Optimized BLAS routines (OpenBLAS, MKL)
import numpy as np

arr = np.arange(10)
print(arr.flags)   # Memory layout information
  C_CONTIGUOUS : True
  F_CONTIGUOUS : True
  OWNDATA : True
  WRITEABLE : True
  ALIGNED : True
  WRITEBACKIFCOPY : False

Vectorization with Boolean Masks

  • Boolean arrays allow filtering without loops.

  • Extremely fast due to C-level implementation.

import numpy as np

arr = np.array([1, 5, 2, 8, 3, 10])

# Loop-based

filtered_loop = [x for x in arr if x > 4]

# Vectorized

filtered_vec = arr[arr > 4]

print(filtered_vec)
[ 5  8 10]

Vectorized Conditional Logic (np.where)

import numpy as np

arr = np.array([1, 2, 3, 4, 5])

# Replace elements < 3 with 0, else keep them

result = np.where(arr < 3, 0, arr)

print(result)
[0 0 3 4 5]

Conclusion

  • Use vectorization whenever possible.
  • NumPy and Pandas provide built-in vectorized operations.
  • Significant performance gains over loops.
  • Reduces memory overhead and improves efficiency.
