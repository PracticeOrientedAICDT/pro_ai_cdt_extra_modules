Introduction to PyTorch and Tensors

Author

Daladier Sampaio Neto

What is PyTorch?

  • Open-source deep learning framework developed by Facebook’s AI Research lab.
  • Known for:
    • Dynamic computation graphs (define-by-run)
    • Strong GPU acceleration
    • Large, active community
  • Widely used in research and production.

Why PyTorch?

  • Pythonic: integrates naturally with Python syntax and libraries.
  • Flexible: easy debugging and model customization.
  • Ecosystem: tools for vision, NLP, and more.
  • Supported by popular cloud platforms and hardware accelerators.

PyTorch Ecosystem Overview

  • PyTorch offers domain-specific libraries:

  • torchvision: computer vision

  • torchtext: natural language processing

  • torchaudio: audio/speech processing

  • torch.nn: neural network modules

  • torch.optim: optimization algorithms (SGD, Adam)

  • torch.utils.data: dataset utilities and dataloaders

torch.nn: Building Neural Networks

Provides:

Layers (Linear, Conv2d, LSTM)

Activations (ReLU, Softmax)

Loss functions (MSELoss, CrossEntropyLoss)

Modular model design

import torch.nn as nn

model = nn.Sequential(
nn.Linear(4, 16),
nn.ReLU(),
nn.Linear(16, 2)
)

print(model)
Sequential(
  (0): Linear(in_features=4, out_features=16, bias=True)

  (2): Linear(in_features=16, out_features=2, bias=True)
)

torch.optim: Optimization Algorithms

  • Popular optimizers:

    • SGD

    • Adam / AdamW

    • RMSprop

Handles gradient updates internally.

import torch.optim as optim

optimizer = optim.Adam(model.parameters(), lr=0.001)

Datasets and DataLoaders

  • PyTorch provides tools to load data efficiently.
from torch.utils.data import DataLoader, TensorDataset
import torch

X = torch.rand(100, 4)
y = torch.randint(0, 2, (100,))

dataset = TensorDataset(X, y)
loader = DataLoader(dataset, batch_size=16, shuffle=True)

for batch_x, batch_y in loader:
  print(batch_x.shape, batch_y.shape)
  break
torch.Size([16, 4]) torch.Size([16])

Pytorch capabilities

  • PyTorch provides:

    • Tensors + GPU acceleration

    • Autograd for gradients

    • Tools for deep learning (nn, optim)

    • Libraries for vision, NLP, audio

    • A complete ecosystem for building AI systems.

What is a Tensor?

  • A tensor is a generalization of vectors and matrices to potentially higher dimensions.
  • Primary data structures in PyTorch.
  • Efficient Computation: Optimized for high-performance mathematical operations, especially on GPUs.
  • Supports automatic differentiation, crucial for training neural networks.

What is a Tensor?

  • multi-dimensional array used to store and manipulate data.
  • Similar to NumPy arrays, but with:
    • GPU support
    • Integration with deep learning workflows
  • Examples:
    • 0D tensor: a single number
    • 1D tensor: a vector
    • 2D tensor: a matrix
    • 3D+ tensor: multi-dimensional datasets

Creating Tensors in PyTorch

import torch

data = [[1, 2], [3, 4]]
x_data = torch.tensor(data)

# From NumPy array
import numpy as np
np_array = np.array(data)
x_np = torch.from_numpy(np_array)

# With random values
x_rand = torch.rand(2, 3)

# With zeros
x_zeros = torch.zeros(2, 3)

Inpecting Tensors

import torch

x = torch.rand(3, 4)

print("Shape:", x.shape)     # tensor dimensions
print("Data type:", x.dtype) # float32, int64, etc.
print("Device:", x.device)   # CPU or GPU
Shape: torch.Size([3, 4])
Data type: torch.float32
Device: cpu

Basic Tensors Operations

x = torch.rand(2, 2)
y = torch.rand(2, 2)

z_add = x + y              # Addition
z_mul = x * y              # Element-wise multiplication
z_matmul = torch.matmul(x, y) # Matrix multiplication
z_reshape = x.view(4)      # Reshape
