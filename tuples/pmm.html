Tuples in Python

  • What are Tuples?

    • In Python, a tuple is an immutable, ordered collection of elements.
    • Defined by placing elements inside parentheses () separated by commas.
    • Example:
(1, 'apple', 3.14)

Tuples in Python

  • Tuples can contain any data type — even other tuples.
  • Once created, you cannot add, remove, or modify elements.

Tuples vs Lists

  • Key Differences

    • Tuples are immutable, while lists are mutable.

    • Tuples are generally faster and use less memory.

    • Tuples can be used as keys in dictionaries (if all elements are hashable).

coordinates = (10, 20)
numbers = [10, 20]

# Tuples cannot be changed:

# coordinates[0] = 15  ❌ -> Error

Why Use Tuples?

  • Immutability ensures data integrity.
  • Faster access and lower memory usage.
  • Can be used as dictionary keys.
  • Ideal for representing fixed data that should not change.

Tuples as Records

  • Tuples as lightweight data structures

    • A tuple can represent a single record — like a row in a database.

    • Each position in the tuple corresponds to a specific field.

person = ("Alice", 30, "New York")

Tuples as Records

  • Representing multiple records
person1 = ("Alice", 30, "New York")
person2 = ("Bob", 25, "Chicago")

people = [person1, person2]

for name, age, city in people:
    print(f"{name} ({age}) lives in {city}")
Alice (30) lives in New York
Bob (25) lives in Chicago

Tuple Unpacking

  • Assign multiple variables at once
person = ("Alice", 30, "Engineer")

name, age, profession = person
print(name)       # Alice
print(age)        # 30
print(profession) # Engineer
Alice
30
Engineer
  • Each variable gets its value based on position.
  • Makes code cleaner and more readable.

Nested Tuples

student = ("Alice", (90, 85, 88))
print(student[0])       # Alice
print(student[1][1])    # 85
Alice
85

Tuples as Dictionary Keys

  • Tuples are hashable
locations = {
(35.6895, 139.6917): "Tokyo",
(40.7128, -74.0060): "New York"
}

print(locations[(40.7128, -74.0060)])
New York

Performance and Efficiency

  • Why tuples are faster than lists?

    • Fixed size → no need to manage dynamic resizing.

    • Stored in memory more efficiently.

    • Ideal for fixed collections of data (e.g., coordinates, RGB values).

When to Use Tuples

  • When you want to ensure data cannot change.
  • When using dictionary keys.
  • When representing records or structured data.
  • When you want better performance than lists.

Dictionaries

Dictionaries in Python

  • What are Dictionaries?

    • A dictionary is an unordered, mutable collection of key-value pairs.
    • Keys must be unique and immutable (e.g., strings, numbers, tuples).
    • Values can be of any data type.
person = {
    "name": "Alice",
    "age": 30,
    "city": "New York"
}

print(person)
{'name': 'Alice', 'age': 30, 'city': 'New York'}

Accessing Dictionary Elements

  • Access values using keys
person = {
    "name": "Alice",
    "age": 30,
    "city": "New York"
}

print(person["name"])   # Output: Alice
print(person.get("age"))  # Output: 30
Alice
30

Accessing Dictionary Elements

  • The method .get() is safer than direct access:

    • Returns None (or a default value) if the key doesn’t exist instead of raising an error.
person = {
    "name": "Alice",
    "age": 30,
    "city": "New York"
}

print(person.get("profession", "Not specified"))

# Output: Not specified
Not specified

Accessing Dictionary Elements

  • The .keys() method
person = {
    "name": "Alice",
    "age": 30,
    "city": "New York"
}

print(person.keys())

if "name" in person.keys():
    print("Key 'name' exists!")
dict_keys(['name', 'age', 'city'])
Key 'name' exists!

Accessing Dictionary Elements

  • The .items() method
person = {
    "name": "Alice",
    "age": 30,
    "city": "New York"
}

print(person.items())

for key, value in person.items():
    print(f"{key}: {value}")
dict_items([('name', 'Alice'), ('age', 30), ('city', 'New York')])
name: Alice
age: 30
city: New York

Summary: Tuples + Dictionaries

  • Tuples → Immutable, ordered, store fixed data

  • Dictionaries → Mutable, unordered, store key-value mappings

  • .get(), .items(), and .keys() make dictionary access safe, readable, and powerful

  • Together they form efficient, expressive data models in Python
